# Naam Jaap Counter 

A simple web-based counter to keep track of **Hare Krishna Naam Jaap**.

## Features

* Increment jaap count with one click.
* Choose round length (108, 27, or 7).
* Automatically counts completed rounds.
* Reset both jaap count and rounds done.
* Green highlight when a round is completed.

## Built With

* HTML
* CSS
* JavaScript
* Bulma CSS

## Purpose

A small practice project built while learning JavaScript DOM manipulation and event handling.
